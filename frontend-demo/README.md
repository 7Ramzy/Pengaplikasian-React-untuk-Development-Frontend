# Uji Persistensi Produk

Gabungkan cabang ini dengan `tugas-2-be` untuk menjalankan demo. Dari direktori `backend`, jalankan `npm install` lalu `npm start` dan buka `http://127.0.0.1:3000/demo/`.

Tambahkan produk uji, mulai ulang backend SQLite, lalu muat ulang daftar untuk memastikan produk tetap tersedia.
